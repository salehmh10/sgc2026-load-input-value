# Manuscript artifact map

The companion contains the manuscript source currently titled *Incremental Value of Weather and Calendar Inputs in Hour-Ahead Load Forecasting*. It is a research manuscript, with author and publication metadata awaiting confirmation. No DOI, acceptance, or publication status is inferred. The author block is intentionally empty.

The `paper/figures/` and `paper/tables/` paths above are reviewed publication snapshots. Run `python scripts/reproduce_artifacts.py` to regenerate three PDF/PNG figures and two numeric tables, copy the fixed conditions table, and write plot records plus a machine-readable verification report under `results/reproduced/{figures,tables,validation}/`. Tracked publication snapshots remain untouched. `--output-dir PATH` writes all assets below another directory; `--check-only` verifies existing outputs without regenerating them. The command resolves its inputs relative to its own location and works from any current working directory. Run `python scripts/build_paper.py` with `pdflatex` and `bibtex` installed to regenerate the assets and overlay them into a separate build directory before compiling. Its `--skip-artifacts` option builds from the tracked publication snapshots. TeX is optional for CSV verification and figure regeneration.

The study-window drawing was extracted from the earlier `reproduce_figures.py`; it requires no older model output. The two I15 figure functions and table formatting were adapted from `reproduce_i15_figures.py`. Numerical plot coordinates and table formatting are preserved. Portable input/output paths, metadata suppression, explicit output verification, and CLI options are new companion code. The conditions table was embedded in the original `main.tex`; extracting it into a separate file changes no table content. The manuscript's scientific prose and bibliography are preserved. Older superseded TiDE-only figures and their CSVs are omitted.

Historical summary files are immutable references. `results/reference/SHA256SUMS.json` records the hashes of admitted CSVs and fixed table references. Reference CSV strings are unchanged, including full precision; output numbers are checked against them. The public path does not independently reproduce model fits, underlying hourly errors, leave-one-seed-out analyses, September sensitivity results, or bootstrap intervals. Those require private input data and the separate experiment workflow. Textual findings beyond these table/plot inputs remain historical manuscript statements, not freshly recomputed results.

The checker verifies 84 accuracy records, 72 aggregate contrasts, 24 seed contrasts, six chronological partitions, 384 stored interval bounds, 48 plotted points (84 numeric coordinates and CI bounds), 66 independently rounded numeric table cells, six inherited persistence cells, and the unchanged conditions table. It checks the direction `condition - FULL`, reconstructs aggregate differences from paired absolute scores, and verifies peak differences against the absolute peak scores. These are fidelity checks to frozen aggregate evidence. They do not create independent evidence for the scientific claims.

Image byte equality is not a reproducibility requirement: Times New Roman is preferred when installed and STIXGeneral is the fallback. Font availability and renderer versions can change PDF/PNG bytes without changing scientific values. Saved image metadata contains no personal paths; plot PDF dates are suppressed. The manuscript disables PDF build dates and engine path metadata. TeX logs remain local build artifacts.
