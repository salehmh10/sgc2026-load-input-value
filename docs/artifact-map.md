# Research figure and table map

The companion reproduces the research outputs for *Incremental Value of Weather and Calendar Inputs in Hour-Ahead Load Forecasting*. The manuscript text, bibliography and TeX bundle are not distributed. The figure/table numbering below identifies the corresponding research outputs without requiring the manuscript source.

| Manuscript item | Publication input | Release output | Output type |
|---|---|---|---|
| Figure 1: chronological windows and observed evaluation weather | `study_windows.csv` | `figures/study_windows.pdf` and `.png` | Generated from partition dates and observed-weather aggregates |
| Table I: seven retrained conditions | `results/reference/expected-tables/conditions.tex` | `tables/conditions.tex` | Fixed textual protocol artifact; copied and checksum-verified |
| Table II: evaluation mean daily WAPE | `i15_accuracy.csv`, `i15_simple_references.csv` | `tables/i15_accuracy.tex` | Generated, rounded to two decimals at presentation |
| Figure 2: primary condition-minus-FULL contrasts | `i15_contrasts.csv`, `i15_primary_seed_points.csv` | `figures/i15_primary_value.pdf` and `.png` | Generated using full stored precision and stored block CI bounds |
| Table III: validation/evaluation contrasts | `i15_contrasts.csv` | `tables/i15_validation.tex` | Generated signed contrasts, two decimal places |
| Figure 3: mean/peak trade-off | `i15_contrasts.csv` | `figures/i15_mean_peak_tradeoff.pdf` and `.png` | Generated; peak changes are descriptive and use complete days |

Input CSVs default to `results/reference/`. Output paths in the table are relative to `results/reproduced/`, or to an explicit `--output-dir`. Run `python scripts/reproduce_artifacts.py` to regenerate three PDF/PNG figures and two numeric tables, copy the fixed conditions table, and write plot records plus a machine-readable verification report. `--check-only` verifies existing outputs without regenerating them. The command resolves its default inputs relative to its own location and works from any current working directory. No TeX installation or manuscript source is required.

For results of a new full experiment, run `liv experiment export --run outputs/paper-run --output outputs/paper-aggregates`, then `liv reproduce --data-dir outputs/paper-aggregates --output-dir outputs/paper-artifacts`. This route creates the same five input CSV schemas from the run's own metrics and preprocessing metadata, including newly computed bootstrap bounds. It records the source execution and never substitutes reference scores for missing results. `liv validate` accepts the same `--data-dir` and `--output-dir` arguments.

The study-window drawing was extracted from the earlier `reproduce_figures.py`; it requires no older model output. The two I15 figure functions and table formatting were adapted from `reproduce_i15_figures.py`. Numerical plot coordinates and table formatting are preserved. Portable input/output paths, metadata suppression, explicit output verification, new-run export and CLI options are companion code. The conditions table was extracted from the original manuscript without changing its content. Older superseded TiDE-only figures and their CSVs are omitted.

Historical summary files are immutable references. `results/reference/SHA256SUMS.json` records the hashes of admitted CSVs and fixed table references. Reference CSV strings are unchanged, including full precision; output numbers are checked against them. The public path does not independently reproduce model fits, underlying hourly errors, leave-one-seed-out analyses, September sensitivity results, or bootstrap intervals. Those require private input data and the separate experiment workflow. Textual findings beyond these table/plot inputs remain historical manuscript statements, not freshly recomputed results.

The checker verifies 84 accuracy records, 72 aggregate contrasts, 24 seed contrasts, six chronological partitions, 384 stored interval bounds, 48 plotted points (84 numeric coordinates and CI bounds), 66 independently rounded numeric table cells, six inherited persistence cells, and the unchanged conditions table. It checks the direction `condition - FULL`, reconstructs aggregate differences from paired absolute scores, and verifies peak differences against the absolute peak scores. These are fidelity checks to frozen aggregate evidence. They do not create independent evidence for the scientific claims.

Image byte equality is not a reproducibility requirement: Times New Roman is preferred when installed and STIXGeneral is the fallback. Font availability and renderer versions can change PDF/PNG bytes without changing scientific values. Saved image metadata contains no personal paths; plot PDF dates are suppressed. A reviewed historical illustration is retained in `docs/assets/` for the README.
